# Airloom 0.1.0 Preview 1

Windows 原生、免驱的 HomePod / AirPlay 音频投放项目，原创代码采用 MIT 许可证。

## 包含内容

- WinUI 3 / C++/WinRT 原生界面，深浅主题、设备卡片、连接动画、真实音频波形及左右声道电平。
- Windows WASAPI loopback：选择当前默认或指定的已有音频输出设备，采集并转换为 44.1 kHz 双声道音频。
- 独立实现的发现、密码认证、PIN 配对、加密会话、ALAC 音频发送、时钟同步与重传。
- 可选 Windows 凭据管理器存储；密码重试、取消和忘记凭据。
- 托盘、可选登录启动、默认关闭的本机静音控制。

## 下载

要求 Windows 11 x64，build 22000 或更高。

- 安装：`Airloom-0.1.0-setup-x64.exe`，按当前用户安装。
- 便携：完整解压 `airloom-windows-x64-portable.zip`，运行其中的 `Airloom.exe`。请保留全部 DLL 和资源文件。
- `SHA256SUMS.txt` 提供这两个文件的 SHA-256。
- `native-window.png`、`native-smoke.json` 是同一次 Windows CI 构建的原生窗口启动证据。

## 验证与已知边界

此版本只从全部构建检查通过的提交发布。已验证 Windows 编译和原生窗口启动、音频算法、认证数学，以及本地合成接收端上的加密会话、错误密码拒绝和音频传输。ALAC 另有 FFmpeg 解码往返检查。

**尚未取得真实 HomePod 的播放测试结果。** 密码保护流程有代码和自动化测试，但不能据此承诺所有 HomePod 型号、固件、家庭访问控制、立体声组合或多房间同步可用。端到端播放延迟尚未测量。

本版本只采集已有输出端点，不会在 Windows 设置中新增虚拟声卡；单独应用采集暂未提供。电脑与接收端需要能够在局域网互相发现和通信。使用的是设备访问密码或配对码，不是 Apple Account 密码。

应用和安装包尚未做发布者代码签名。请参阅仓库 README、协议文档和 Windows 音频说明了解测试范围及故障报告信息。
