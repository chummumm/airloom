# Airloom 0.4.4

## 音源、路线与扬声器

- 同步新的原生 WinUI 界面：声音来源集中在顶栏，路线舞台展示当前音源与所选扬声器之间的关系，扬声器列表与固定底部控制栏分工更清晰。
- 路线节点、连线和粒子跟随真实核心状态；连接、等待认证、播放及错误各有对应呈现。波形与电平继续读取真实音频数据。
- 保留紧凑窗口优先显示扬声器、固定音量读数槽位、系统／应用声音来源切换、原生立体声组合和先左后右测试音。
- 设置页重新整理层次，继续提供主题、波形、设备可见性、诊断、登录启动及应用更新。

## 动效与操作

- 加入路线绘制、节点回弹、状态脉冲、发现雷达、刷新旋转与设置切换过渡；遵循系统减少动画和高对比度偏好。
- 窗口隐藏、最小化或离开主页时停止主页连续动效，重新显示时按当前状态恢复。
- 已有设备播放而另一台等待密码时，主按钮“停止投放”直接停止当前投放；需要认证的设备继续使用各自的密码操作。

## 保留的音频行为

- 连接时读取设备原有音量，不另存本地音量，也不在启动、连接或切换音源时覆盖扬声器；只有用户手动调节滑块才发送音量设置。
- 重新发现、切换系统输出、切换应用及来源类型继续保留已有 AirPlay 会话。Windows 采集切换期间可能短暂静音。
- 无应用选择、应用退出或来源不可用时保留连接并静音等待，不自动转播其他来源。
- 保留独立设备认证、托盘、正常退出、更新校验及安装包清理。

## 验证与安装

发布要求 Linux／Windows 协议和核心回归、真实 Windows 采集及来源通知 API 生命周期、原生编译与打包、UI Automation 界面交互、不同窗口尺寸和深浅主题、以及更新退出与清理检查通过。

界面测试中的扬声器、应用和音频由独立的 CI fixture 提供，替代 DLL 不进入安装包；相关截图以 `fixture-` 命名。无设备的启动与布局检查使用发货核心。本次不新增 HomePod 真机、声学同步或实际播放延迟的验证结论。

Windows 11 x64。可在设置中检查更新，或下载 `Airloom-0.4.4-setup-x64.exe`；便携版请完整解压后运行。程序、安装包和更新器版本同步为 0.4.4。
