# Airloom 0.1.1

修正初次建立 HomePod / AirPlay 会话时，可能导致 `session SETUP` 返回 400 的请求格式问题。

## 修复

- 将 SETUP 中的六字节 `macAddress` 与八字节设备标识区分，保留完整的设备及 PTP 时钟身份。
- PTP `ClockID` 按有符号 64 位整数编码，保留原始位模式，避免编号最高位为 1 时被写成 128 位 plist 整数。
- 补齐 PTP peer 的 UUID、设备类型和时钟端口匹配能力字段；只有 NTP 会话声明 `timingPort`。
- 添加针对二进制请求格式和发送请求的回归检查。

## 下载与升级

要求 Windows 11 x64（build 22000 或更高）。

- 安装版：`Airloom-0.1.1-setup-x64.exe`。先从托盘退出旧版，再运行新安装包。
- 便携版：完整解压 `airloom-windows-x64-portable.zip` 到新目录，退出旧版后启动新的 `Airloom.exe`。
- 校验值：`SHA256SUMS.txt`。

发布为 GitHub **Latest**。安装包、便携版和原生启动证据均来自同一个成功的 Windows 构建，标签指向该构建的源码提交。

## 验证范围

修复依据是对请求字段与已有接收端兼容实现的协议行为核对，以及新增的回归检查。**用户的 HomePod 尚未用此补丁完成重试，不能把自动化测试当作实机修复成功的确认。** 若仍报错，请提供新的完整错误提示、HomePod 型号和系统版本；不需要提供密码或配对凭据。

应用和安装包尚未添加发布者代码签名。立体声组合、多房间同步和端到端播放延迟仍未实测。
