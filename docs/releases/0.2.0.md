# Airloom 0.2.0

针对“已经连接、波形正常、HomePod 却没有声音”的反馈修正播放时钟报文，并加入多设备投放、独立设置页与应用内更新。

## 播放与连接

- 修正 PTP 播放时间公告的 RTCP 长度字段，并按独立接收端的解析规则修正 RTP 与播放时间的映射。
- 对必须跟随接收端时钟的 HomePod，在建立会话前学习接收端的时间线，保持会话与音频公告中的时钟身份一致。
- 同一网卡上的多个连接共用 PTP 监听端口，分别维护每台设备的时钟和会话，解决第二台设备占用同一端口而无法连接的问题。
- 一次采集电脑声音，再通过独立有界队列发送给每台设备。投放中可勾选、取消或重试单台设备；第二台设备等待密码或失败时，已有投放继续。
- 显示真实声音采集状态，提供“试播 3 秒”测试音，帮助区分声音来源与接收端播放问题。

## 设置与更新

- 齿轮打开独立原生设置页，保留主题、动态波形与登录启动设置。
- 设备可隐藏和恢复，隐藏选择在重启后保留；已离线的隐藏设备也能恢复显示。隐藏正在投放的设备只断开该设备。
- 增加“检查更新”，使用 GitHub 最新正式发布版本；发现新版后可下载并安装。
- 更新包通过 HTTPS 下载并进行 SHA-256 校验，原生更新助手等待旧应用退出后安装、重新启动应用并清理安装包。
- 取消、失败或中断后的应用内更新文件会清理；下次启动会重试清理仍被占用的残留。清理范围仅限 Airloom 自己的更新缓存。

## 下载与升级

要求 Windows 11 x64（build 22000 或更高）。

- 安装版：`Airloom-0.2.0-setup-x64.exe`。从 0.1.x 升级时，先从系统托盘退出旧版，再运行新安装包。
- 便携版：完整解压 `airloom-windows-x64-portable.zip` 到新目录，退出旧版后运行新的 `Airloom.exe`。
- 校验值：`SHA256SUMS.txt`。

从本版本起可通过设置页检查后续更新。应用内更新使用安装程序更新当前运行目录；手动下载到“下载”文件夹的安装包不属于自动清理范围。

## 验证范围

协议回归包含独立抓包 fixture、接收端的播放时间计算、完整加密 PTP 会话和非零音频的独立解码，以及多个目标共用监听端口时的隔离。Windows 构建检查会实际启动便携包、打开和返回设置页，并验证更新助手的校验拒绝、安装或取消、重新启动和包清理流程。

用户已确认 0.1.1 能建立会话、采集到声音并发送数据，但 HomePod 无声。0.2.0 修正了可以独立验证的报文缺陷；**实际是否恢复该 HomePod 的声音，仍需本版本实机复测**。原生立体声组合、跨设备精确同步和端到端播放延迟也仍需实机验证。
