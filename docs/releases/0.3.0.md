# Airloom 0.3.0

这一版集中重做完整原生界面。用户已反馈 0.2.1 在其 HomePod 上恢复出声；0.3.0 沿用这一版的音频采集、AirPlay 协议、密码认证和多设备发送实现。

## 全新声音工作区

- 将声音来源、实时声音和扬声器按使用顺序排列；宽窗口并排显示仪表和设备，紧凑窗口上下排列。
- 固定底部播放控制栏：开始／停止、音量、本机静音和试播始终有明确位置。音量百分比采用等宽数字和固定宽度，状态变化不会挤动控制。
- 银灰浅色和石墨深色主题使用同一套间距、字号、边框与交互状态；设置入口整合到原生标题栏。
- 深色音频仪表直接显示真实 PCM 的峰值包络、左右声道电平、格式、时间和发送包数。包络按固定 −60 至 0 dB 标尺绘制，没有音频时不生成假信号。
- 设备以紧凑行显示名称、连接状态、选择和密码提示；刷新状态时保留控件身份、键盘焦点和固定布局。

## 设置与交互

- 设置页重排为应用更新、连接诊断、外观与启动、设备显示四个功能组。
- 保留主题切换、动态波形、登录启动、隐藏／恢复设备、诊断复制和凭据管理。
- 密码和配对仍使用原生对话框。单台设备的认证可以取消，其他已选设备保持连接。
- 保留原生键盘操作、系统高对比度、减少动画偏好，以及安装更新时退出进程并清理托盘的流程。

## 下载

- `Airloom-0.3.0-setup-x64.exe`：Windows 11 x64 安装版。
- `airloom-windows-x64-portable.zip`：完整解压后运行。
- `SHA256SUMS.txt`：安装包与便携包的 SHA-256 校验值。

已经安装 0.2.1 的用户可在设置中检查更新。应用内下载的安装包会按更新缓存规则自动清理。若仍从 0.1.x／0.2.0 升级，请先通过系统托盘中的“退出 Airloom”结束旧程序，再运行安装包。

## 原生界面验收

发布流程要求完整 Linux 和 Windows 检查成功，包括从最终便携包启动真实 WinUI 窗口、880／1100／1600 像素窗口布局、0／9／10／99／100 音量值、实际鼠标拖动、固定底部控制栏、设置导航、在线更新检查、诊断复制与深浅主题切换。

发布页中的 `native-*`、`settings-window.png` 来自真实发布程序。`fixture-*` 截图同样使用这个 WinUI 可执行文件，但在独立临时目录中以 CI 专用替代 DLL 提供模拟的设备和信号，用于验收两台设备传输、第三台设备需要密码、取消单台认证和长名称布局。替代 DLL 不进入安装包或便携包；这些截图不作为真实音频传输或实际多设备播放的证明。

HomePod 实机出声的确认来自用户对 0.2.1 的反馈。立体声组合、不同型号／固件兼容性、多设备精确同步和端到端播放延迟仍需实机验证。
