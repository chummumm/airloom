# Airloom 0.4.2

## 原生界面重构

- 接入本次提供的 `App.xaml`、`MainWindow.xaml`、`MainWindow.xaml.h` 和 `MainWindow.xaml.cpp`，采用 Windows 11 Mica 背景、Fluent 原生控件和系统强调色。
- 重排声音来源、投放状态、波形与扬声器区域；保留宽窗口并排、紧凑窗口扬声器优先及固定底部播放控制。
- 统一设置卡片、设备行、更多操作与原生按钮反馈；播放中的主按钮显示“停止投放”。
- 连接状态、设备选择和页面过渡使用原生动画，并遵从 Windows 的动画偏好。波形继续使用音频核心提供的真实信号。

## 立体声文案

- 删除界面中的“兼容性验证”和“仍待验证”提示；组卡与无障碍名称使用“原生立体声组合”。
- 同步清理音频核心中的两句旧状态文案，避免从诊断或其他状态路径重新出现。
- 保留“测试左右声道”：先左、短暂静音、后右，共 3 秒。

## 集成与验证

应用和设备列表的事件更新、明确选择应用、音量交互、组合隐藏及离线恢复、密码/配对、托盘退出和更新包清理保持既有行为。无障碍名称测试与新文案同步，原有交互、布局及发布检查继续执行。

安装包只从 Windows/Linux 完整检查成功的构建发布；随附实际 WinUI 运行截图和检查记录。截图中的 fixture 设备、应用和音频信号是测试数据。此次界面重构和文案调整不新增 HomePod 双机实机播放验证结论；协议能力范围见[立体声说明](https://github.com/chummumm/airloom/blob/main/docs/stereo.md)。

Windows 11 x64。可在设置中“检查更新”，或下载本版安装包；便携版请完整解压后运行。
