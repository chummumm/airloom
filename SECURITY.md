# Security

Do not post passwords, pairing keys, Windows credential blobs, or unredacted network captures in public issues. The application should never need an Apple Account password.

AirPlay device passwords and pairing information are used only to connect to the selected local-network receiver. Remembering credentials is opt-in and uses the Windows current-user credential store. There is no cloud account or telemetry endpoint in Airloom.

For a suspected vulnerability, open a minimal issue that describes the affected component and asks for a private contact route without publishing an exploit or secret. Compatibility reports must redact local device identifiers and authentication data.
